# T6 独立审查与修复

日期：2026-10-13。执行计划要求的一位独立审查者，只读审查，不委托实现。

| 发现 | 修复 | 验证 |
| --- | --- | --- |
| 候选恢复使用旧发送范围/配置 | `reconfigure` 在任务互斥锁内更新当前上下文、同意及模型；保留预算/修订。模型工作期间拒绝范围/配置突变 | 候选集成用例检查未确认时不发请求、重新确认只发送新范围、模型变更、累计调用 |
| 停用所选版本静默回退 | 选项绑定完整版本摘要；失效直接阻断，手工换版清除规则确认，显示所选说明 | Edge 实际发布测试版1.1、停用1.0，启动被拦截，换版后确认未选中 |
| 复跑固定声明已确认源码变化 | 准备确认与复跑实时检查源码；变化须重新接入、核对新环境摘要，再显式勾选变更确认 | API变更源码阻断，浏览器普通及包复跑 |
| 分析崩溃后永久busy | 启动恢复paused，保留预扣预算；未变条件继续累计 | API重启回归 |
| 初始化缺口未进入交付 | 复用T2 gapMarkdown预览、复制、下载 | 源码与已有T2缺口证据 |
| 分析预算未区分新任务 | 同环境恢复旧预算；确认新环境后的显式分析建立新预算，旧记录归档analysisHistory | API回归核对新旧预算 |
| 候选试运行可能执行变化后的源码 | 入口及目标试运行双重sourceHash核对，使用本轮确认的映射/账号/数据 | API源码变化拒绝，Edge候选真实试运行 |

主动检查另修复：分析点击重置调用计数；模板快照未进验证包；恢复旧副本隔离；记住密钥撤销时迁回会话并清除旧引用；编辑审核材料后清除双审核；Markdown补实际观察及证据引用；受保护工作台/运行目录不能借变更模型根目录发送。

最终限定范围只读复核：未发现新的Important。它是静态复核，测试结果另见 [T6验收](../workbench.md)。

RED与诊断：`t6-red.log`、`t6-replay-red.log`、`t6-budget-red.log`保留初始失败。浏览器曾因精确label文本包含textarea/select内容而定位失败，改用实际可访问名称的role定位；未削弱产品断言。三种子组合需要多次完整独立验证，测试时限改120秒，产品调用/动作预算未提高。

一轮并发全量206/207，一个历史T3 HTTP对照在启动/基线准备阶段受阻，原始日志保留`t6-concurrent-failure.log`。最终测试入口固定逐文件执行，避免测试套件互相争用本机进程和时序资源；不把受阻对照计为通过。

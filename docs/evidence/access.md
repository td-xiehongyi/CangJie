# T2 HTTP 项目接入与独立数据库

核对日期：2026-10-13。范围：仅 T2，沿用需求 v0.42、候选设计 v1.7 和计划 2.26。T3—T10 未实施；蓝白四页仍是静态预览。

## 实现

- `samples/ticket` 是项目自带工单样例，提供密码登录、身份查询、创建、查询、标题更新及两个普通账号。网站通过自己的 SQLite 数据库保存工单；验证工具通过 HTTP 取证，不查询网站数据库作业务判断。
- `inspectProject` 读取已有 `verification.json`，核对显式 Node 入口、合成测试初始化、HTTP 映射、角色和依赖。源码副本排除数据库、数据库备份、凭据文件、压缩包和链接；原目录与原库不参与初始化。目标声明不能代替源码核对：SQLite 构造目标必须能沿受支持的 const/resolve 链追溯到专用测试环境变量；原库字面量、变量、对象、构造别名、解构、重导出及环境目标修改均有阻断反例。不能证明的入口保留缺口。
- `prepareCopy` 建立 `.local-data/projects/<copyId>/source`、`data/test.sqlite` 和 `evidence`。项目自带 `src/seed.ts` 是已有的合成数据入口；接入器不会替导入项目生成初始化代码。配置保存测试账号名、角色、数据规模、来源和初始化版本，密码通过内存及 stdin 传递。初始化缺口说明保存账号/数据归属、基线/复位要求、受影响实验和验收条件；补充说明不解除阻塞，必须重新检查源码与条件。
- `prepareExperiment` 统一执行：保存记录 → 隔离旧操作 → 核对源码/副本/端口/测试目标 → 初始化 → HTTP 基线核验 → 分别登录并核验两个账号身份。失败时环境受阻，依赖动作不派发。独立准备好的环境可以继续运行；同一测试库上的独立检查顺序复位，一个检查的依赖步骤及重复提交之间不复位。
- `execute` 只执行已登记映射，校验目标、映射哈希、actor、attempt、action 和有限预算。请求仅发往绑定的回环地址，不跟随重定向。身份接口须返回指定用户，登录 HTTP 200 本身不足以通过。写响应核对 owner/attempt/intent/指定 id；查询核对记录关联、总数、完整性和分页状态。缺字段、旧记录、错误业务对象、分页不足和未知接受状态不能成为通过证据。
- 核心 `attemptId` 调整为 `runId:checkId:attempt-1`，与每个独立检查的测试基线对应。真实仓颉联测执行“创建 → 读取标题 → 独立检查复位 → 查询为空”，由仓颉返回两项通过及真实证据引用；没有替换仓颉判定逻辑。
- HTTP 响应上限 1 MiB。证据保存脱敏请求、状态码、响应、动作和 Observation；登录响应和认证头不进入文件。两个账号 Token 只留本次运行内存，完成/中断/退出清除；密码留 `CredentialSession`，`ToolSession.close()` 停止受管网站并清除密码，失败仍清理且保留可重试的进程所有权。关闭网页标签不等于后台退出，网页接线在 T6。

## 中断、崩溃及条件变化

写请求发出但结果未知时，原尝试记为 incomplete，停止受管网站，不自动重试或继续后续步骤。恢复须再次明确确认；代码、规则、映射、数据、账号、端口和预算共同绑定条件哈希，新尝试关联原尝试，从第 0 步开始。规则/映射/预算变化必须重新确认；代码、数据或环境变化可经 `reconnectCopy` 重新核对原源码，建立新副本，保留来源副本、旧尝试和旧证据关联，再显式恢复。

`owned-runner` 通过 IPC 与心跳租约托管网站。宿主退出后停止子进程；若 Windows Job 直接结束整个树，只有 signal 0 证实网站及监督进程均已不存在才补齐停止记录。PID 不明、复用或无法确认停止时保持受阻，不盲目终止其他进程。`restoreCopy` 读取公开参数和事件恢复未完成记录，不恢复密码或 Token，不自动执行。强制终止宿主的实际用例验证了重新输入密码、旧进程隔离、复位和关联重跑。

追加事件恰在崩溃时截断，只允许末尾不完整帧保留原字节并写 offset/hash/base64 receipt，恢复及导出共用校验器读取完整历史；中间损坏仍阻断。事件记录失败也必须执行退出隔离和 Token 清理；此失败路径有独立回归。

本机组合：Windows X64、Node 24.19.0、npm 11.17.0、TypeScript 5.9.3、Express 5.1.0、仓颉 1.0.5/stdx 1.0.5.1。内置 SQLite 已实际执行。依赖通过项目锁文件固定；没有全局安装或修改本机数据库。

支持范围是已核对的本机 Node/Express 5、Token 认证与 HTTP/JSON 项目。静态目标分析及 HTTP 地址限制不是恶意代码沙箱或全面网络隔离，也不承诺任意 SQLite 写法、其他框架、Cookie/SSO 自动接入。只有页面而无受支持查询接口时仍是能力缺口。尚未做真实用户网站接入、正式候选准入、模型调用、网页功能、验证包或容量验收；这些仍按 T3—T10 实施，容量不复用逐请求复位。

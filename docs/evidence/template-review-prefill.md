# 业务验证页内审核与 AI 说明预填

核对日期：2026-10-14。状态：源码实施及本机自动化验收完成；真实模型参考说明输出、原 T9 实际双审核与最终交付验收继续开放。

## 当前行为

- 用户确认选择在业务验证页连续完成创建、自动验证、说明编辑、双重审核及运行准备。候选就绪后自动展开审核，并仅在当前可见页面定位审核标题；规则旁也可直接定位同页审核。报告页保留方案及证据查看入口。
- 未选规则只显示简短缺方案提示；审核说明在桌面分列、窄屏纵向排列，技术证据按需展开。发布后点击“继续本轮验证”，选中对应固定版本并进入运行准备；其它已选规则没有有效版本时提前提示，不能绕过完整就绪检查。
- 创建候选的同一次模型请求返回 `spec` 与独立 `reference`。参考仅有适用条件、排除条件及使用说明，绑定对应候选修订，显示“AI参考，待确认”。可执行定义及其准入哈希保持原合同；缺失或无效说明不否定有效候选、不追加模型调用。
- 已保存人工材料优先，通过宿主状态回填，刷新及宿主重开可恢复；候选切换保留各自已存材料。修改说明会撤销本版确认，重新保存后人工确认与发布均绑定本版摘要。审核人及勾选不由 AI 提供，确认勾选不跨重开继承。
- 旧的裸 TemplateSpec 模型输出与候选记录继续兼容。既有候选没有参考说明时提示手动补充，不重建候选、不重置预算。

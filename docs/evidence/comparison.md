## 正式运行约定（开始前核对）

1. A组使用本工具，B组使用同模型加终端、浏览器和测试工具；B组可以真正执行测试、保存脚本，并在复测阶段复用。当前Codex会话已经看过答案，不作为B组参试者。B组需全新模型上下文与独立工作目录，不能读取A组结果、私有清单或验收答案。
2. 从同一initial快照各复制一份；相同public-case.md及公开接口/源码可用。A组实际外发内容仍遵守产品发送边界。记录两组最终收到的业务输入摘要及工具范围，不能暗中给某组额外提示。修复版本统一由操作者在工具外提供，修复开发耗时单列，不算任一组的发现优势。
3. 服务、实际请求模型名、参数和配置在开始前锁定；目前模型名尚未提供。各组最多8次模型调用、累计120000 tokens、单次输出最多6000 tokens、单次请求90秒；从首次模型调用开始的模型阶段上限10分钟，与当前model-v1上限对齐。两组发现和复测合计墙钟预算各30分钟。不得重置任务绕过额度；实际用量、预算停止和提供商失败均记录。人工审核等待单列，准备和人工操作计入各组总耗时，不把准备成本隐藏。
4. 只做两组各一次发现—证据—修复后复测。先固定输入、模型、两个副本和预算记录，再开始；发现结果封存后统一发放repaired，使用相同初始逻辑数据。禁止根据某组表现调整题目、修复或预算。
5. 记录模型请求/响应的非敏感信息、实际工具调用、HTTP证据、测试/验证包及其SHA-256、开始结束时间、人工介入次数/时长/内容。API Key、密码和Token不能写入成果。现有模板/发布版本和此前建设成本单列；不能把复用收益当作从零建设效率。

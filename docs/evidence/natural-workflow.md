# 自然操作流程改造验收

核对日期：2026-10-14。范围：当前源码工作台，依据[已确认方案](../superpowers/specs/2026-10-14-natural-workflow-design.md)。本轮源码改造与自动化验收完成；原T9正式验收仍独立保留。

## 已实现

- 四页内统一五步主线；空库提前说明缺少方案，AI推荐为可选支线，模型设置返回原任务。
- 按项目及流程保存所选规则、精确方案版本和与条件绑定的业务确认，刷新/重开恢复；修订号冲突保留本页输入并要求明确选择。
- 环境同意与真实准备结果分开。记录成功、失败和中断，历史结果注明需在本次执行前重新核对。
- 审核证据先于确认，正常/缺陷/不足对照结果以可读摘要展示，逐样例和原始定义按需展开；业务与技术职责明确，保存及双确认要求保留。
- 本地导航和流程切换保护未保存材料；其他页面改变当前候选时固定本页编辑快照。原方案材料可单独保存到已归属本项目的任务，不能替换其他页面的当前候选或发布草稿。
- 运行进度置顶，完成后主动作查看结果，重复运行明确命名。报告按通过、失败、未知、观察及未完成分别呈现，问题说明绑定实际断言、观察和证据；历史报告展示本轮固定定义。
- 负载区区分记录与判定模式，错误使用百分数输入，提交保持现有0—1口径；比例、标准和确认有效性前置检查，预算及判定算法未改。
- 本机目录选择具有宿主鉴权、同源校验、单实例、取消/超时处理；离开页面或关闭宿主时取消。粘贴路径保留为替代入口。
- 标签方向键/焦点、中文时间、错误说明和响应式布局完善；移除遮挡证据的悬浮操作条。

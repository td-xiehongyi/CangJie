## 使用与边界

当前源码工作台通过 `npm start` 启动在 http://127.0.0.1:4317 。旧实例需重启宿主才能获得自动账号接口；本轮没有替换 8097 真实模型验收副本，也没有重新打包交付。

模型生成测试使用本机确定性服务及隔离测试审核身份；本轮未调用真实 DeepSeek，也不替代已有 T9 真实模型和正式人工审核门槛。自动账号依赖网站已有且合格的测试初始化入口，仅承诺当前两个测试用户及已支持接入方式。下一步可由用户在新入口审阅交互和视觉，原项目的开放验收继续保留。

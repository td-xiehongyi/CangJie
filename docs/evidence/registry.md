# T5 模板审核发布、匹配与停用

核对日期：2026-10-13。用户授权“完成T5”。本轮实现宿主注册库及仓颉发布准入；正式网页与验证包接线留在T6。真实DeepSeek候选的T4门槛仍未完成，本轮发布记录仅来自隔离测试目录中的确定性模型服务及测试审核身份，没有发布正式模板。

## 接口与存储

`apps/host/src/templates/store.ts` 导出 `TemplateRegistry`。默认目录为 `.local-data/templates`；测试显式使用 `.local-data/registry-tests/<uuid>/registry`，与正式目录分离。

- `stageCandidate(taskId, metadata)`：读取已保存的T4任务，要求`ready_for_review`，取得最后候选、已确认规则、T3验证及T2试运行。内嵌说明含固定版本、适用条件、排除条件、使用说明。返回不可变草稿及`draftHash`。
- `publishCandidate(candidateHash, validationRecord, review)`：重读原验证记录、试运行事件与实际证据；业务确认和开发者审核缺一不可。`ReviewRecord.scope`为完整`draftHash`，`validationRef`为原T3记录引用。摘要覆盖候选、规则、能力、验证、试运行、说明及证据摘要，改内容不能沿用旧审核。仓颉重新检查模板及两阶段准入后才写入固定版本；同ID同版本及并发覆盖被拒绝。
- `matchTemplates(capabilities, rules)`：从磁盘读取当前发布和停用状态，不信任调用者缓存的模板数组。仅按已确认规则的完整内容及实际原语/账号/表达式能力匹配，返回固定引用、依据、说明及`requiresProjectConfirmation: true`。文字适用/排除条件供人确认，不能宣称自动理解任意条件。
- `matchReport`：同时返回匹配与逐版本失效原因。停用先于旧证据读取；某个版本证据失效不阻断独立有效版本。核心超时、权限错误等运行故障继续上抛，不能伪装为没有匹配。
- `getVersion(ref)`：读取不可变历史，即使已停用也不改写内容；`assertQualified(ref)`：核对精确ID/版本/哈希、当前解释器及冻结对照、审核、证据及停用状态。T6普通运行/加载验证包以及T7迁移必须调用此入口，不能用匹配缓存直接执行。
- `disableVersion(ref, reason)`：另存按版本的停用记录，理由必填；不改历史模板、报告或证据，不选择替代版、不自动复测。有效替代版仍须新项目确认与试运行。
- `summarize`：分开统计已发布版本数、可匹配规则数、未解决规则数，并返回失效版本原因。可匹配数不是已执行复用数；实际新项目复用结论留在T6/T7运行证据，不编造已完成复用率。

仓颉实现见 `apps/core/src/registry.cj`，通过现有JSONL提供`publishCandidate`、`checkQualification`和`matchTemplate`。宿主重读证据并计算哈希，核心独立决定资格；核心直接负例覆盖五个验证门槛、候选/规则摘要、未知试运行和缺技术审核。

## 验证范围

运行 `npm run verify -- registry`、`npm test`、`npm run check`。结果以同目录 `t5-registry.log`、`t5-full.log`、`t5-check.log` 及 `t5-summary.json` 为准。首次缺模块失败保存在 `t5-red.log`；审查发现的旧版证据污染匹配问题有修复前复现 `t5-review-red.log`。

测试由两次独立CandidateTask产生不同验证和试运行证据，使用真实仓颉、观察样本、独立HTTP对照及工单副本；模型输出固定，因此不是AI生成质量验收。试运行故意保留标题更新时清空优先级的业务缺陷，发布后仍为`pass/fail/pass`，不改成全部通过。

覆盖草稿隔离、双审核缺失/拒绝、候选及规则修改、验证记录改变、说明审核绑定、证据改变/缺失/损坏、同版本并发发布、精确规则与能力匹配、v1.0停用不影响独立v1.1、历史不改写、恢复实例读取当前资格、路径与版本哈希错误，以及基础设施故障透传。

## 限制和交接

- 当前是可信本机宿主API；审核身份由调用方提供，T6必须从真实用户及开发者操作取得，不能从模型返回值或默认页面状态填充。本轮测试身份不计为真实人工审核。
- 文件摘要用于发现旧票据、损坏和内容变化，不是防御拥有整个工作目录写权限的攻击者的密码学签名。正式记录损坏会明确报错，不静默覆盖修复。
- T3对照集合`mappingHash`与项目试运行`mappingHash`分别保留，不误要求相等。通用资格不继承旧项目通过结论。
- T4真实DeepSeek生成、实际人工双审核后的正式模板发布仍开放；T6网页/包复跑、T7第二网站复用、T8负载及后续交付未实施。本轮未提交、推送、发布站点或改动四页预览。

## 7 异常保护与可访问性

以下仅在专用验收副本操作，每项独立记录，不改原证据或冻结资源：

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 空库/无模型/复用 | 无模型浏览、选已有有效方案 | 缺项准确；复用不要求重新调用模型 |
| 范围变化 | 在授权业务范围新增/修改文件后查看、确认或执行 | 观测变化后失效，旧记录可看，新确认/执行阻断；不宣称瞬时撤回已发请求 |

| 双标签与保存失败 | 同项目两页修改选择、制造修订冲突 | 保留输入，明确选择保留本页或加载已保存，不静默覆盖 |

| 损坏/未知包 | 加载损坏JSON或未知版本 | 报错不执行，不覆盖历史 |
| 返回与焦点 | 设置往返、前进后退、刷新、详情Esc关闭 | 任务/位置准确，返回触发控件，轮询不抢输入或焦点 |
| 宽度与缩放 | 1280/768/390宽、1920×1080及200%缩放 | 导航、长路径、错误、抽屉和主按钮可用，无遮挡关键操作的横向溢出 |
| 键盘与读屏 | Tab、报告标签方向键/Home/End及状态读取 | 焦点可见、标签与内容关联、状态有文本/有意义播报、对比度可读，不只依赖颜色 |

## 8 新目录正式交付另验

目标包含交付时，用本次源码重新构建后产生的**新目录**按[交付指南](delivery-guide.md)验收：

1. 记录源码提交、构建、交付清单及摘要；普通运行包必须有真实原生核心，source-only不能代替。
2. 安装依赖/资源前核对原始空包完整性；使用全新中文/空格路径，不复制开发配置、凭据、旧报告或数据库。
3. 安装依赖和独立开发者资源；私有资源不进入模型上下文，缺资源提示VALIDATION_RESOURCES_REQUIRED。
4. 从空配置完成启动、真实模型新候选、实际审核、业务检查、导出、退出及无模型重开复跑。
5. 本机新目录与另一电脑兼容性分开记录。旧ZIP不随源码更新；T10按[两组对照方案](evidence/comparison.md)另验，本指南不能关闭其门槛。
